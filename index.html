1. 원본 파일 업로드

여러 개의 XLSX 또는 CSV 파일 선택

  • 선택한 파일이 없습니다.
STEP 02 · 업로드 후 실제 열 선택

2. 검색할 열 선택 및 조건 입력

파일을 추가하면 아래에서 파일·시트를 선택하여 실제 열 제목과 샘플 값을 확인할 수 있습니다. 열을 선택하고 글자를 입력하면 해당 열에 포함된 행만 추출합니다. 파일 목록이 갱신되지 않으면 아래 오류 메시지를 확인하세요.

파일을 올리면 A열, B열, C열과 첫 행의 제목이 표시됩니다.

파일 업로드 전

원본 파일을 올리고 열과 검색어를 지정하세요. 예: '업체명' 열 선택 → '한화' 입력 → 검색 결과 미리보기 → 한 시트로 XLSX 생성.

검색 미리보기
업로드된 파일이 없습니다.

여러 파일에 같은 의미의 열이 서로 다른 위치에 있으면 열 위치(A/B/C...)가 아닌 파일별 열 매핑이 필요합니다. 여러 파일에 동일한 제목이 있으면 제목명을 우선 매칭하고, 없으면 선택한 열 위치를 사용합니다. 필터로 제거된 행에 걸친 병합 셀·사진 배치는 달라질 수 있습니다.

STEP 03 · 결과 저장

3. 전체 병합 / 조건 추출 다운로드

전체 병합은 검색 조건에 관계없이 모든 행을 보존합니다. 조건 추출은 위에서 선택한 열과 검색어를 기준으로 일치하는 행만 저장합니다.

🔎

조건에 맞는 행 추출

위에서 선택한 열에 검색어가 포함된 행만 추출합니다.

준비 완료

보존 범위 및 주의 사항

  • 지원: 값, 수식, 기본 셀 스타일, 병합 셀, 행 높이, JPEG/PNG/GIF 일반 삽입 사진 및 사진 위치의 행 오프셋 이동
  • 주의: 다른 시트·파일을 참조하는 수식은 병합 후 결과가 달라질 수 있습니다. 서로 다른 열 너비·인쇄 설정은 한 시트에서 동시에 유지할 수 없습니다.
  • 제한: 차트, SmartArt, 도형, 매크로, 피벗, 복잡한 조건부 서식, 이미지 특수 효과는 정확히 보존되지 않을 수 있습니다.
  • CSV 입력에는 원래 삽입 사진이나 셀 서식이 없습니다. 사진 보존 결과는 XLSX로만 저장할 수 있습니다.

ExcelJS 라이브러리(ExcelJS, JSZip)를 인터넷에서 불러옵니다. 기업 네트워크에서 차단되는 경우에는 동작하지 않을 수 있습니다. 파일 내용은 이 페이지에서 처리되며 병합 서버로 업로드되지 않습니다.
